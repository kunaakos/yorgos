# `@yorgos/experimental`

An actor library written in TypeScript. It aims to be a loose and simple implementation of the concept. **It runs in browsers**, does **transparent remoting** and is modular.

See the [project repo's Readme](https://github.com/kunaakos/yorgos) for more info and guidance.

## Versioning

This package will be deprecated once the project matures, and will be replaced with `@yorgos/core` and other packages under the same scope.
